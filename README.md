**Uber Data Analytics Dashboard**

**Overview**
The Uber Data Analytics Dashboard is an interactive Power BI project designed to analyze and visualize Uber ride data. This dashboard helps understand business 
performance by tracking important metrics such as bookings, revenue, cancellations, customer ratings, trip trends, and vehicle performance.

**Features**
1.Revenue and booking analysis
2.Ride cancellation tracking
3.Customer rating insights
4.Vehicle type performance comparison
5.Payment method analysis
6.Interactive filters and KPI cards
7.Dynamic charts and visualizations

**Tools & Technologies Used**
1.Power BI
2.Power Query
3.DAX

**Objectives**
The main objective of this project is to convert raw ride data into meaningful insights that help improve decision-making and business understanding through 
interactive visual reports.

**Key Insights**
1.Identified top-performing vehicle categories
2.Analyzed cancellation patterns and ride trends
3.Compared customer ratings across vehicle types
4.Tracked revenue generation and booking performance

4.Business analytics

6.Report building using Power BI
